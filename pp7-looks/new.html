ProPresenter 7 Standard Operating Guide

Standardized workflow, automation timelines, and Look configurations for VCBA Media.

1. Master Sunday Playlist Timeline

We have consolidated our production workflow down to a single master template: REGULAR_SUNDAY_TEMPLATE. This replaces all previous variations (such as separate First Sunday configurations) to ensure an absolute linear flow.

Service Segment Standard Operating Workflow / Action
PRE-SERVICE & COUNTDOWN Automated rolling loops and video countdowns kick off via the built-in Scheduler. No operator actions required.
WORSHIP The core song selection pulled straight from the standard Song library. Make sure text layers line up cleanly.
ANNOUNCEMENT & T&O Tithing, offering segments, slides, and active church life media.
SERMON The active series presentation package followed immediately by the Benediction.
POST-SERVICE Automated exit media loops take over the screens seamlessly.
🍞 First Sunday Communion Protocol: On the first Sunday of the month, do not switch playlists or alter the template structure.
  1. Select the VCBAMEDIA folder under the Library panel.
  2. Locate the Communion presentation asset.
  3. Drag and drop it directly into the active REGULAR_SUNDAY_TEMPLATE playlist under the WORSHIP or ANNOUNCEMENT & T&O header.
  4. Post-Service: Right-click the Communion item and remove it from the playlist to keep the template clean for the following week.
2. Calendar & Timeline Automation

Pre-service transitions are completely automated using ProPresenter’s Calendar Scheduler. The operator does not need to manually trigger announcements, the stream, or the countdown loop.

📍 How to Open the Calendar Window: Because the default keyboard shortcut (Ctrl + Alt + C) often conflicts with Windows system graphics hotkeys and may fail to open, always use the application menu: View -> Calendar.

Scheduled Time Event Name Triggered Action / Playlist Item Purpose & Behavior
9:40:00 AM Pre-Service Loop Announcement Loop Presentation Automatically fires rolling announcement graphics out to the house screens.
9:50:00 AM Start Livestream Start Streaming Action Command Automated Go-Live. Instructs ProPresenter to output the active RTMP stream to social platforms.
9:55:00 AM 5 Min Countdown 5 Min Countdown Video / Timer Switches the house presentation seamlessly to the official 5-minute countdown video.
⚠️ Critical Automation Notes for Operators:
  • Calendar Status: The Calendar Enabled checkbox in the top-left of the Calendar settings must always remain checked. Disabling this turns off all automated service transitions.
  • Testing New Events: When creating separate event items, always ensure the repeat rule and ends on dates match the exact schedule of that specific event so it does not loop or conflict with the standard Sunday morning master timeline.

4. Media Bin Background Standards

To maintain clear visual separation and reduce the chance of an operator selecting the wrong asset mid-service, the Media Bin utilizes dedicated background playlists:

  • 🖼️ Worship Background: Reserved strictly for abstract motion loops, ambient pads, and song lyrics presentation layers.
  • 📖 Verse Background: Reserved specifically for sermon aesthetic packages, scripture reading backdrops, and sermon series graphic templates.
