1 — What is a Macro?

ProPresenter 7 utilizes Macros to handle complicated multi-screen tasks seamlessly under the hood with a single click. Instead of requiring local production volunteers to manually configure multi-layered screens dynamically during a live transition, target configuration templates have been directly integrated onto the slides via automated Actions.

A Presentation/Theme now functions automatically via background-routing rules to dictate precisely how text styles, screen properties, graphic overlays, and downstream output displays layout their data safely in the live ecosystem.
